V7Brief d'animation — prêt pour le développement
Implémentation de la direction A retenue en V5. Une seule primitive, appliquée par IntersectionObserver ; le CSS porte l'animation, le JS ne fait qu'ajouter une classe.
1 · Primitive CSS
.reveal { opacity: 0; transform: translateY(12px); transition: opacity .22s cubic-bezier(.2,.8,.2,1), transform .22s cubic-bezier(.2,.8,.2,1); } .reveal.is-visible { opacity: 1; transform: translateY(0); } .reveal-group > * { transition-delay: calc(var(--i, 0) * 90ms); } @media (prefers-reduced-motion: reduce) { .reveal, .reveal.is-visible { transition: none !important; opacity: 1 !important; transform: none !important; } }
2 · Déclencheur JS (une fois, léger)
const io = new IntersectionObserver((entries) => { entries.forEach(e => { if (e.isIntersecting) { e.target.classList.add('is-visible'); io.unobserve(e.target); } }); }, { threshold: 0.25 }); document.querySelectorAll('.reveal') .forEach(el => io.observe(el));
Déclenchement une seule fois par élément (unobserve après entrée) — jamais de re-jeu au scroll arrière. Aucune dépendance : vanilla JS, ~15 lignes.
3 · Où l'appliquer, section par section
Hero (02) — pas de reveal : visible dès le premier paint (specs §9/§12).
Démo Manager (03) — reveal groupe : label puis fenêtre produit, --i 0/1.
Démo terrain (04) — reveal groupe : texte (--i 0–2) puis téléphone en dernier (--i 3), comme en V5.
Tension (05) — reveal simple sur le bloc photo + citation.
Brief à la preuve (06) — fondu de panneau à chaque changement d'onglet (transition déjà en 07, pas un reveal au scroll).
Photo hospitalité (07) — reveal photo puis liste des 4 principes, --i 0–4.
Pourquoi Choucas (08) — reveal séquencé avant → Choucas → après (--i 0/1/2), chiffres en dernier.
Journée (09) — reveal sur le changement de moment actif (fondu court, pas de scroll-reveal).
Profils (10) — reveal groupe des 3 cartes, --i 0–2.
CTA final (11) — reveal simple sur le bloc entier.
Garde-fous (specs §8 / §12)
— Rien au-dessus de la ligne de flottaison ne doit être animé au premier paint.
— Aucun parallaxe, aucun scroll-jacking, aucun texte animé en continu.
— Durée 180–240 ms, easing cubic-bezier(.2,.8,.2,1) partout.
— prefers-reduced-motion: reduce supprime toutes les transitions — testé avant recette.
— CLS : les cadres produit et photos réservent leur hauteur avant chargement (pas de saut au reveal).
